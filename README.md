# HFK_글쓰는 OOO_글구조템플릿

책이나 뉴스레터 **한 권의 전체 구조를 한 장에 짜는 작업표**입니다.
위고 「아무튼, ___」 시리즈처럼 하나의 소재를 붙잡고, 시기별 챕터에 **메인 플롯 ·
서브플롯 · 공간 · 인물**을 걸어 전체 지도를 그립니다. 손으로 그리던 구조 워크시트를
그대로 디지털로 옮긴 것입니다.

## 바로 쓰기

👉 **https://huijeong06.github.io/writing-structure-template/**

링크를 열면 바로 입력할 수 있습니다. 설치·회원가입 없이 브라우저만 있으면 됩니다.

## 기능

- 상단 **이런 분에게 추천합니다!**(＋ 추가하기·Enter로 줄 추가) · **브런치북 소개**(500자 카운터) — 브런치북 연재 신청 화면과 같은 칸
- **칸 클릭 → 바로 입력**, 모든 변경은 **그 브라우저에 자동 저장**(새로고침해도 유지)
- 맨 위 제목도 클릭해 자기 소재로 바꾸기
- **＋ 행 추가** / 행 번호에 마우스를 올려 **✕** 로 중간 행 삭제 / **－ 마지막 행 빼기**
- **💾 내 파일로 저장**(맨 위) — 쓰기 전에 먼저 눌러 내 파일을 만들고 그 파일에서 쓰기. 쓴 내용이 담긴 나만의 페이지(「HFK_글쓰는 OOO_글구조템플릿.html」 파일)를 내려받기. 더블클릭하면 어느 기기에서든 그대로 열려 이어 쓰기
- **🖨 인쇄 / PDF** — 가로 A4 한 장에 맞춰 종이에 그대로 출력
- 기본 **15행**(목차 15개 안팎 기준) — 첫 행은 프롤로그, 끝 행은 에필로그로

## 열 구성

| 열 | 쓰는 것 |
|---|---|
| No. / Time | 순서 · 시기(연도) |
| Chapter (source) | 챕터 제목 · 출처 |
| Plot (Main) | 그 챕터의 메인 줄기 |
| Sub Plot 1–5 | 곁가지 이야기 다섯 갈래 |
| Space | 공간 · 장소 |
| Character | 인물 |

## 가져가 쓰기

- 저장은 각자 브라우저에만 남으니 **여러 명이 같은 링크를 써도 서로 안 섞입니다.**
- 오프라인에서 쓰려면 `index.html` 한 파일만 내려받아 더블클릭하면 됩니다(자체완결형).
- 포크·수정 자유입니다.
